# What is this?

Circle Alchemy is a simulation of circles moving through a toroidal space where they can merge, busrsting into small splinters after reaching a certain mass.
There are more things to it, and more that I'll be adding to this.

# How to use it?

For now the only way is to compile it, or run it in a IDE.
